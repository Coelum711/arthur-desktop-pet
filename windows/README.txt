亚瑟·柯克兰桌宠（Windows 版）
================================

【怎么打开】
1. 把整个压缩包解压到一个固定的地方（比如 D:\Arthur），不要只拖出一个 exe。
2. 双击 "Arthur Desktop Pet.exe"。
3. 第一次打开 Windows 可能会弹出蓝色的"Windows 已保护你的电脑"：
   点"更多信息"→"仍要运行"。（这个程序没有买微软的签名，所以会这样提示。）
4. 亚瑟会出现在屏幕右下角，站在任务栏上面。

【他在哪儿 / 怎么关】
- 任务栏右下角的托盘里有一个小爪印图标（可能藏在"^"里面）。
  点它可以：隐藏/叫他回来、换大小、透明度、眼镜、开机自动启动、退出。
- Ctrl+Alt+A：显示 / 隐藏他
- Ctrl+Alt+P：完全穿透（鼠标直接穿过他，打游戏或者录屏时用）

【可以对他做什么】
- 点一下他：会弹出"戳一下"菜单（聊天、喝茶、魔法、换衣服、偷他口袋里的东西……）
- 按住拖：把他拎起来。拎得高、拎得久，他会从生气变成害怕；甩出去会撞墙。
  抓胸口、头顶、手、脚、尾巴，反应都不一样。
- 摸头、摸脸颊、摸尾巴、握手……鼠标放在他身上慢慢蹭就行。
- 把文件拖到他身上：他会看一眼文件名（不会打开文件）。
- 惹他生气他会走掉一阵子，晚点自己回来；也可以送他点东西或者握握手哄他。

【他自己的生活】
- 他按自己的作息过日子：早上喝茶、看书、种花、出门散步、晚上弹吉他，
  深夜会缩到屏幕角落盖上小毯子睡觉。
- 不联网，不需要任何服务器，也不收集任何东西。
  他的记性（衣服、口袋里的东西、今天被你欺负了几次）存在：
  %APPDATA%\Arthur Desktop Pet\

【已知还没做的】
- 会爬到别的窗口顶上走来走去，也会跳下来；拖动窗口时他会站在上面跟着走，窗口最小化或切换桌面时他会撑伞飘下来。
- 按截图键他暂时不会有反应。

有问题欢迎在 GitHub 上提 issue，附上截图就好。
